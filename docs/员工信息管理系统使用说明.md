# 劳务公司员工信息管理系统 - 使用说明

## 项目概述

这是一个完整的劳务公司员工信息管理系统，基于现有工业信息化管理框架扩展而来。

### 主要功能

- 📇 **员工管理**：员工信息录入、编辑、删除，身份证OCR识别
- 🏢 **企业管理**：合作企业信息管理
- 📋 **岗位管理**：岗位发布、管理、发布状态控制
- 💰 **工资管理**：工资录入、发放管理、工资历史
- 📝 **报名管理**：员工岗位报名、面试流程管理
- 🎉 **通知中心**：生日提醒、节日祝福、系统通知

## 技术栈

### 后端
- NestJS - 企业级Node.js框架
- TypeORM - ORM框架
- SQLite/MySQL/PostgreSQL - 数据库支持

### 前端
- Vue 3 - 渐进式JavaScript框架
- TypeScript - 类型安全
- Element Plus - UI组件库
- Vue Router - 路由管理

## 快速开始

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
# 同时启动前端和后端
pnpm dev
```

或者分别启动：

```bash
# 启动后端API服务
cd apps/api
pnpm dev

# 启动前端Web服务
cd apps/web
pnpm dev
```

## 功能模块说明

### 1. 员工管理

- 查看员工列表
- 添加新员工
- 编辑员工信息
- 删除员工
- 支持身份证OCR自动识别（预留接口）
- 员工状态管理（在职/离职/待入职）

### 2. 企业管理

- 查看合作企业列表
- 添加新企业
- 编辑企业信息
- 删除企业
- 企业合作状态管理

### 3. 岗位管理

- 查看岗位列表
- 添加新岗位
- 编辑岗位信息
- 发布/下架岗位
- 删除岗位
- 岗位薪资、地点、要求管理

### 4. 工资管理

- 查看工资列表
- 添加工资记录
- 编辑工资信息
- 标记工资发放
- 删除工资记录
- 自动计算应发/实发工资

### 5. 报名管理

- 查看报名列表
- 添加报名记录
- 编辑报名信息
- 管理报名状态（待处理/面试中/已录用/已拒绝）
- 记录面试安排和结果

### 6. 通知中心

- 查看系统通知
- 标记通知已读
- 支持多种通知类型（生日、节日、系统、工资、面试）

## 数据库配置

系统支持多种数据库，通过环境变量配置：

### 使用SQLite（默认）

无需额外配置，系统自动创建SQLite数据库文件。

### 使用MySQL

```env
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=industrial_dev
```

### 使用PostgreSQL

```env
DB_TYPE=postgres
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=industrial_dev
```

## API接口说明

### 员工接口
- `GET /api/employees` - 获取员工列表
- `GET /api/employees/:id` - 获取员工详情
- `POST /api/employees` - 创建员工
- `PUT /api/employees/:id` - 更新员工
- `DELETE /api/employees/:id` - 删除员工
- `POST /api/employees/ocr` - 身份证OCR识别

### 企业接口
- `GET /api/companies` - 获取企业列表
- `POST /api/companies` - 创建企业
- `PUT /api/companies/:id` - 更新企业
- `DELETE /api/companies/:id` - 删除企业

### 岗位接口
- `GET /api/positions` - 获取岗位列表
- `GET /api/positions/published` - 获取已发布岗位
- `POST /api/positions` - 创建岗位
- `PUT /api/positions/:id` - 更新岗位
- `PUT /api/positions/:id/publish` - 发布岗位
- `DELETE /api/positions/:id` - 删除岗位

### 工资接口
- `GET /api/salaries` - 获取工资列表
- `GET /api/salaries/employee/:employeeId` - 获取员工工资历史
- `POST /api/salaries` - 添加工资
- `PUT /api/salaries/:id` - 更新工资
- `PUT /api/salaries/:id/paid` - 标记发放
- `DELETE /api/salaries/:id` - 删除工资

### 报名接口
- `GET /api/applications` - 获取报名列表
- `POST /api/applications` - 创建报名
- `PUT /api/applications/:id` - 更新报名
- `DELETE /api/applications/:id` - 删除报名

### 通知接口
- `GET /api/notifications` - 获取通知列表
- `PUT /api/notifications/:id/read` - 标记已读

## 常见问题

### 如何切换数据库？

修改环境变量 `DB_TYPE` 为 `sqlite`、`mysql` 或 `postgres`，并配置相应的数据库连接信息。

### 如何添加新功能模块？

1. 在 `apps/api/src/modules/` 下创建新模块
2. 创建实体、服务、控制器、模块文件
3. 在 `app.module.ts` 中注册新模块
4. 在前端创建对应的页面组件
5. 在路由中添加新页面

### 数据如何备份？

- SQLite：直接备份数据库文件
- MySQL/PostgreSQL：使用对应的数据库备份工具
