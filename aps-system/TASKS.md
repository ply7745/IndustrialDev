# APS系统完整开发任务清单

## 项目概述
基于微信公众号文章《APS 高级计划与排程——关键点分析（落地项目案例）》的46个核心流程，开发完整的APS系统。

## 技术栈
- **后端**: NestJS + TypeScript + TypeORM
- **前端**: Vue 3 + TypeScript + Element Plus
- **数据库**: PostgreSQL 15
- **缓存**: Redis
- **测试**: Jest
