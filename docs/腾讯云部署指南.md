## 准备工作

### 1. 购买腾讯云服务器
推荐配置：
- **CPU**：2核及以上
- **内存**：4GB及以上
- **系统**：Ubuntu 20.04/22.04 LTS 或 CentOS 7/8
- **带宽**：3Mbps及以上

### 2. 获取服务器信息
购买后，您需要：
- 服务器公网IP
- SSH登录用户名（一般是 root 或 ubuntu）
- SSH登录密码或密钥

## 方式一：一键脚本部署（推荐）

### 第一步：登录服务器

使用 SSH 登录您的腾讯云服务器：

```bash
# 使用密码登录
ssh root@您的服务器IP

# 或使用密钥登录
ssh -i 您的密钥文件.pem root@您的服务器IP
```

### 第二步：运行一键部署脚本

在服务器上执行以下命令：

```bash
# 下载并运行部署脚本
curl -O https://raw.githubusercontent.com/您的仓库/main/deploy-tencent.sh
chmod +x deploy-tencent.sh
./deploy-tencent.sh
```

或者，直接在服务器上创建并运行：

```bash
# 创建部署脚本
cat > deploy-tencent.sh << 'EOF'
#!/bin/bash
set -e

echo "========================================="
echo "  劳务公司员工信息管理系统 - 腾讯云部署"
echo "========================================="

# 1. 更新系统
echo ""
echo "📦 更新系统..."
apt-get update && apt-get upgrade -y

# 2. 安装 Docker
echo ""
echo "🐳 安装 Docker..."
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# 3. 安装 Docker Compose
echo ""
echo "📦 安装 Docker Compose..."
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 4. 启动 Docker 服务
echo ""
echo "🚀 启动 Docker 服务..."
systemctl start docker
systemctl enable docker

# 5. 验证安装
echo ""
echo "✅ 验证安装..."
docker --version
docker-compose --version

# 6. 克隆或复制项目
echo ""
echo "📂 设置项目..."

# 这里您需要根据实际情况修改：
# 方式A：如果使用 Git 仓库
# git clone https://github.com/您的用户名/您的仓库.git
# cd 您的仓库

# 方式B：如果手动上传项目，先上传到服务器，然后：
# cd /path/to/your/project

echo ""
echo "🎉 环境准备完成！"
echo ""
echo "下一步："
echo "1. 将项目文件上传到服务器"
echo "2. 进入项目目录"
echo "3. 运行: docker-compose up -d --build"
echo ""
EOF

chmod +x deploy-tencent.sh
./deploy-tencent.sh
```

## 方式二：手动部署（完整步骤）

### 步骤 1：连接到腾讯云服务器

```bash
# SSH 连接
ssh root@您的服务器IP
```

### 步骤 2：系统更新和基础软件安装

```bash
# 更新系统
apt-get update && apt-get upgrade -y

# 安装基础工具
apt-get install -y curl wget git vim
```

### 步骤 3：安装 Docker

```bash
# 下载 Docker 安装脚本
curl -fsSL https://get.docker.com -o get-docker.sh

# 运行安装脚本
sh get-docker.sh

# 启动 Docker 服务
systemctl start docker
systemctl enable docker

# 验证安装
docker --version
```

### 步骤 4：安装 Docker Compose

```bash
# 下载 Docker Compose
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 添加执行权限
chmod +x /usr/local/bin/docker-compose

# 验证安装
docker-compose --version
```

### 步骤 5：上传项目到服务器

在您的本地电脑上，使用 SCP 或 SFTP 上传项目：

```bash
# 在本地电脑执行，上传整个项目
scp -r /path/to/your/workspace root@您的服务器IP:/root/
```

或者使用 Git（推荐）：

```bash
# 在服务器上执行
cd /root
git clone https://github.com/您的用户名/您的仓库.git
cd 您的仓库
```

### 步骤 6：启动服务

```bash
# 进入项目目录
cd /root/workspace  # 或您的项目目录

# 使用 SQLite 启动（推荐）
docker-compose up -d --build

# 或使用 MySQL
# docker-compose -f docker-compose.mysql.yml up -d --build
```

### 步骤 7：验证部署

```bash
# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

现在访问：http://您的服务器IP

## 方式三：GitHub Actions CI/CD（持续部署）

### 创建 GitHub Actions 工作流

在项目中创建 `.github/workflows/deploy.yml`：

```yaml
name: 部署到腾讯云

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout 代码
        uses: actions/checkout@v3

      - name: 部署到腾讯云
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.TENCENT_HOST }}
          username: ${{ secrets.TENCENT_USERNAME }}
          key: ${{ secrets.TENCENT_PRIVATE_KEY }}
          port: 22
          script: |
            cd /root/workspace
            git pull
            docker-compose down
            docker-compose up -d --build
            docker image prune -f
```

### 配置 GitHub Secrets

在您的 GitHub 仓库中添加以下 Secrets：

- `TENCENT_HOST`：您的服务器IP
- `TENCENT_USERNAME`：SSH用户名（如 root）
- `TENCENT_PRIVATE_KEY`：您的SSH私钥内容

## 配置腾讯云安全组

部署前，请确保腾讯云安全组开放以下端口：

| 端口 | 协议 | 说明 |
|------|------|------|
| 80 | TCP | HTTP 访问 |
| 443 | TCP | HTTPS 访问（如果启用） |
| 22 | TCP | SSH 管理 |

配置步骤：
1. 登录腾讯云控制台
2. 进入云服务器 -> 安全组
3. 选择您的实例安全组
4. 添加规则，开放上述端口

## 配置域名（可选但推荐）

### 1. 购买域名
在腾讯云或其他域名服务商购买域名。

### 2. 配置 DNS 解析
在域名服务商处添加 DNS 记录：
- 类型：A 记录
- 主机记录：@ 或 www
- 记录值：您的服务器IP

### 3. 配置 HTTPS（Let's Encrypt）

```bash
# 在服务器上安装 Certbot
apt-get install -y certbot python3-certbot-nginx

# 获取证书
certbot --nginx -d 您的域名.com -d www.您的域名.com

# 自动续期
certbot renew --dry-run
```

## 数据备份策略

### 定期备份脚本

创建备份脚本 `/root/backup.sh`：

```bash
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/root/backups"

mkdir -p $BACKUP_DIR

# 备份 Docker volumes
docker run --rm -v labor_data:/data -v $BACKUP_DIR:/backup alpine tar czf /backup/labor_data_$DATE.tar.gz -C /data .

# 保留最近 7 天的备份
find $BACKUP_DIR -name "labor_data_*.tar.gz" -mtime +7 -delete

echo "✅ 备份完成: labor_data_$DATE.tar.gz"
```

设置定时任务：

```bash
# 编辑 crontab
crontab -e

# 添加每日备份（每天凌晨2点）
0 2 * * * /root/backup.sh
```

## 常见问题

### Q: Docker 安装失败怎么办？

A: 尝试使用腾讯云镜像源：
```bash
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
```

### Q: 如何修改默认端口？

A: 编辑 `docker-compose.yml`：
```yaml
ports:
  - "8080:80"  # 将主机端口改为 8080
```

### Q: 数据存储在哪里？

A: 使用 Docker volumes 存储，数据不会因容器删除而丢失。

### Q: 如何迁移数据到新服务器？

A: 
```bash
# 在旧服务器备份
docker run --rm -v labor_data:/data -v $(pwd):/backup alpine tar czf /backup/data.tar.gz -C /data .

# 传输到新服务器
scp data.tar.gz root@新服务器IP:/root/

# 在新服务器恢复
docker run --rm -v labor_data:/data -v /root:/backup alpine tar xzf /backup/data.tar.gz -C /data
```
